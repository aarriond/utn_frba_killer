# CONTRIBUTING - Reglas para Aportar
Para que la calidad de los prompts se mantenga alta, todos los Pull Requests deben respetar un estándar estricto.

## 1. Issues antes de Pull Requests
Para evitar trabajo duplicado, antes de armar el prompt de una materia nueva, abrí un **Issue** con el título "Propuesta: [Nombre de la Materia]". 

## 2. Validación Empírica Obligatoria
Todo PR debe incluir una captura de pantalla o un enlace público donde se demuestre que la IA asume el rol correctamente y respeta las directivas de **no** dar la respuesta directa.

## 3. Resolución de Conflictos y Política de Copyright (Fair Use)
Si hay debates técnicos sobre el contenido, la validación final se hará consultando el programa oficial de la cátedra.
Está **estrictamente prohibido** incluir material protegido por derechos de autor (enunciados de parciales exactos, diapositivas, libros). Usá dudas formuladas con palabras propias o reformulá los ejercicios cambiando los valores y el contexto.

## 4. La Regla de Oro: Las 6 Secciones
No se aceptarán aportes que no incluyan estas 6 secciones con sus títulos exactos:
1. Identidad y Contexto
2. Alcance y Límites
3. Reglas Pedagógicas y de Formato
4. Convenciones de Hardware / Entorno
5. Directivas de Uso Responsable y Prevención de Atajos
6. Prompts de Inicio
